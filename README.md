# 🤖 AI Bash Toolbox

مكتبة شاملة واحترافية من سكربتات Bash الموجهة لمهندسي وباحثي الذكاء الاصطناعي (AI / Machine Learning Engineers).  
توفر الأدوات الأساسية لإعداد المشاريع، إدارة البيانات، تتبع وتدريب النماذج على عدة GPUs، المراقبة اللحظية، الصيانة، وحاويات Docker.

## 🚀 التثبيت والتهيئة

```bash
# استنساخ المستودع
git clone https://github.com/tahadeab-ai/bash-script.git ai-bash-toolbox
cd ai-bash-toolbox

# إعطاء صلاحيات التشغيل لجميع السكربتات
chmod +x run.sh 0*/*.sh
```

---

## 📖 دليل الاستخدام السريع

يمكنك تشغيل كافة المهام عبر الواجهة الموحدة `run.sh`:

```bash
# عرض قائمة الأوامر والمساعدة
./run.sh help

# إنشاء هيكل مشروع ذكاء اصطناعي جديد
./run.sh setup my_vision_project

# مراقبة أداء كروت الشاشة لحظياً
./run.sh monitor

# فحص صحة الموارد والنظام قبل إطلاق التدريب
./run.sh health
```

## 🛠️ تفاصيل الأدوات والسكربتات

### 01_setup: الإعداد والبيئات
- **`setup_project.sh <project_name>`**: ينشئ هيكل مجلدات معياري (`data/`, `models/`, `configs/`, `logs/`, `checkpoints/`, `scripts/`) مع ملفات `.gitignore` و `config.yaml` و `requirements.txt`.
- **`env_setup.sh <env_name> [py_version]`**: ينشئ بيئة Conda، يحدث pip، ويثبت مكتبات البيانات الأساسية (NumPy, Pandas, Scikit-learn)، PyTorch مع CUDA، أدوات Hugging Face، وحزم التتبع (W&B, TensorBoard).

### 02_data: البيانات والتحميل
- **`download_data.sh <name> <url>`**: تحميل الملفات الكبيرة عبر `wget` مع دعم استئناف التحميل عند انقطاع الاتصال (`-c`) والفك التلقائي للملفات المضغوطة (`.tar.gz`, `.zip`, إلخ).
- **`inspect_data.sh <file>`**: تحليل سريع للملفات (عدد الأسطر، الحجم، أول وآخر الأسطر، أسماء الأعمدة للـ CSV وفحص الحقول المفقودة).

### 03_training: التدريب المتوازي والتجارب
- **`train_parallel.sh`**: يكتشف كروت الشاشة المتاحة ويوزع تجارب الـ Hyperparameter بالتوازي على عدة GPUs مع إدارة الطوابير.
- **`experiment_manager.sh <experiments.csv>`**: يقرأ جدول المعاملات (`lr`, `batch_size`, `epochs`) ويشغل التدريب ويسجل النتائج مرتبة حسب الدقة.
- **`resilient_trainer.sh [max_retries]`**: حارس تدريب ذكي؛ يعيد تشغيل التدريب تلقائياً في حال حدوث انقطاع غير متوقع مع مهلة انتظار وتسجيل لكل محاولة.

### 04_monitoring: مراقبة النظام والـ GPU
- **`monitor_gpu.sh [refresh_sec]`**: لوحة قيادة طرفية مدمجة تحدث بيانات استهلاك الذاكرة، نسبة استخدام المعالج الرسومي، درجة الحرارة، استهلاك الطاقة، والعمليات الجارية.
- **`system_health.sh`**: فحص صحة الخادم قبل إطلاق الأحمال الثقيلة، مع تحذيرات عند تجاوز عتبات الاستخدام الآمن للـ RAM والقرص الصلب.

### 05_maintenance: النسخ الاحتياطي والصيانة
- **`backup_results.sh [remote_dest]`**: أرشفة مضغوطة لمجلد النتائج مع إمكانية المزامنة البعيدة عبر `rsync` وحذف النسخ القديمة تلقائياً.
- **`cleanup_checkpoints.sh [num_to_keep] [mode]`**: تفريغ المساحة بالاحتفاظ بآخر N نقاط تفتيش (Checkpoints) أو أفضلها دقة وحذف النماذج المكررة.

### 06_docker: إدارة Docker و CUDA
- **`docker_manager.sh <build|run|shell|clean|test-gpu>`**: واجهة مبسطة لبناء الحاويات وتشغيل التدريب بداخلها مع تفعيل دعم الـ GPUs والـ Volumes وتنظيف النظام.

### 07_utils: أدوات الفحص وتحليل السجلات
- **`api_test.sh <openai|huggingface|local|health|download>`**: أدوات curl جاهزة لاختبار واجهات الذكاء الاصطناعي السحابية والمحلية والتأكد من استقرار الاتصال.
- **`log_analyzer.sh <log_file>`**: استخراج مؤشرات الأداء (Loss, Accuracy, Errors, Warnings) من ملفات سجلات التدريب دون تصفح مئات الصفحات يدوياً.

## 📝 إعداد متغيرات البيئة (.env)

يمكنك إنشاء ملف `.env` في جذر المشروع لحفظ المفاتيح والإعدادات:
```env
OPENAI_API_KEY=sk-...
HF_TOKEN=hf_...
DATA_DIR=./data/raw
```

## 💡 نصيحة احترافية (Alias)

لتشغيل الصندوق من أي مجلد على خادمك بكل سهولة، أضف هذا السطر إلى ملف `~/.bashrc`:

```bash
echo 'alias ai="~/ai-bash-toolbox/run.sh"' >> ~/.bashrc
source ~/.bashrc
```

ثم يمكنك تنفيذ المهام مباشرة:
```bash
ai setup deep_learning_nlp
ai monitor
ai health
```
